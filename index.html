Capstone Project

Markets Mad Scientists is a market-trend analysis application designed for students, beginners, researchers, and small business owners. The system is intended to collect market data, visualize historical patterns, identify trends, and generate simple predictions in a clear interface.

Future development can add a real API, secure user accounts, a database, saved watchlists, and a Python machine-learning backend.
