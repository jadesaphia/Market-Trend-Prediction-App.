# Market Trend Prediction App

## Team Name

Markets Mad Scientists

## Project Description

Markets Mad Scientists is a capstone project designed to make market data easier for beginners to understand.

The application allows users to view market information, examine historical trends, and explore simple predictions based on historical market data.

## Current Features

- Market dashboard
- Market search
- Historical trend chart
- Market price display
- Trend indicators
- Prediction results
- Prediction confidence
- Market explorer
- Demo login
- Responsive website design

## Current Technologies
